## How I Think About Engineering

I treat applications as **long-lived systems**, not just collections of features.

That means:
- Separating domain logic from frameworks
- Being intentional about state ownership and data flow
- Choosing testing approaches based on risk, not dogma
- Measuring before claiming “faster” or “better”
- Making tradeoffs explicit and documented in decision records
